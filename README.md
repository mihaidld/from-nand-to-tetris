# Course Build a Modern Computer from First Principles: From Nand to Tetris

#### Description:

Work performed during following the course Build a Modern Computer from First Principles: From Nand to Tetris parts I and II (https://www.nand2tetris.org/)

Completed all projects and assignments for part I (projects 1-6) and II (projects 7-12).

#### Nand to Tetris part I:

In this project-centered course we build a modern computer system, from the ground up. There are six hands-on projects from constructing elementary logic gates all the way through creating a fully functioning general purpose computer.
In the process, we learn - in the most direct and constructive way - how computers work, and how they are designed.

#### Nand to Tetris part II:

In this project-centered course we build a modern software hierarchy, designed to enable the translation and execution of object-based, high-level languages on a bare-bone computer hardware platform. In particular, we implement a virtual machine and a compiler for a simple, Java-like programming language, and we develop a basic operating system that closes gaps between the high-level language and the underlying hardware platform.
In the process, we gain a deep, hands-on understanding of numerous topics in applied computer science, e.g. stack processing, parsing, code generation, and classical algorithms and data structures for memory management, vector graphics, input-output handling, and various other topics that lie at the very core of every modern computer system.

#### Topics:

- Hardware Architecture
- Computational Logic
- Data Storage
- System Design and Implementation
- Software Architecture
- Algorithms
- Data Structures
- Object Oriented Programming (OOP)
- System Programming
- Computer Graphics Techniques
- Operating Systems
- Virtual Machines
