Variables:
Create and maintain 2 symbol tables for class and subroutine 
which reset after each compilation of class / subroutine
varName type kind position
Position in order in which it's declared (1st -> 0, 2nd -> 1)
x int local 0 -> for var local variables (var int x, z;)
y boolean argument 1 -> for arguments function f(int w, boolean y){...}
b char this 1 -> for field class variables (field char a, b;) (previously pointer 0 has been set to this object)
c int static 0 -> for static class variables (static int c;)
Variable declaration doesn't generate code, just updates subroutine's symbol table

Expressions
codeWrite(exp):
if exp is number n: 
    output 'push n' (push constant n)
if exp is 'variable var': 
    output 'push var' (push local 2) from symbol table
if exp is 'exp1 op exp2: (binary)
    codeWrite(exp1) 
    codeWrite(exp2) 
    output 'op'
if exp is 'op exp': (unary)
    codeWrite(exp)
    output 'op'
if exp is f(exp1, exp2,...):(function call)
    codeWrite(exp1)
    codeWrite(exp2),...
    output 'call f'
