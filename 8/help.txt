Label conventions:
functionName -> (<filename>.<functionName>) e.g. Main.foo
label inside functioName -> (<filename>.<functionName>$<labelName>) e.g. Main.foo$bar
internal label inside functioName (e.g. for if-else)-> (<filename>.<functionName>$<labelName>) e.g. Main.foo$bar
return address inside functionname (for call) -> (<filename>.<functionName>$ret.<counter>) e.g. Main.foo$ret.0, Main.foo$ret.1
