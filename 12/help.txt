multiply(x,y):

    shiftedX = x; // variable that's going to change its value every time 
                  // we shift x to left and pad with 0's to the right
    for i in 0...w-1 do // w is the length of a word (16 bits in Jack)
        if ((i'th bit of y) == 1): // we start with least signigicant bit of y 
                                   // from right to MSB left
            sum = sum + shiftedX
        shiftedX = shiftedX * 2 // shifts x to left // 0110 becomes 1100
        // shift can be implemented by addition: shiftedX = shiftedX + shiftedX

Math.divide
//Returns integer part of x/y, where x >= 0, y > 0
naive: how many times remove y from x as long remainder >= y 
divide(x,y):
    div = 0;//initialize counter to 0
    rem = x
    while rem >= y do //
        rem = rem - y
        div += 1
    return div

Improved:
keep dividing dividend by 2 times divisor, and remember 
to multiply later result by 2 (+1 at certains steps)
using recursion O(log n): uses only addition 
(because subtraction and multiplication  can be implemented as an addition)
divide(x,y):    
    if (y>x) return 0
    q = divide(x,2*y) // divide x by double of y
    if((x-2*q*y) < y) // if remainder < y return result * 2 (since we used double)
        return 2*q
    else
        return 2*q + 1 // else

Math.sqrt
using binary search algorithm 
because sqrt monotonic (grows steadly in proportion to x) and 
its inverse x^2 easily computed as x*x
// computes integer part of y = sqrt(x)
// find integer y such that y^2<= x < (y+1)^2 for 0<=x<2^n
// by performing binary search in the range 0...2^(n/2) - 1

// finds n such that x <= 2^n, then computes j = ceiling(n/2)-1 and 
// result is sum of some powers of 2: 2^j + 2^(j-1) + ... + 2^0
// powers are skipped if sum of powers found so far (starting from largest) is above x
sqrt(x):
    y = 0
    for j = ceil(n/2) - 1...0 do
        if (y + 2^j)^2 <= x then y = y + 2^j
    return y

Heap
Use linked list to keep track of available free heap segments
after de-alloc
Every element (segment) of linked list has:
overhead: 2 words
- next pointer to next element
- size of element (size data block + 2 for overhead)
data part: RAM area available for allocation of size size

During init free = entire heap is available 
and freeList contains one long segment

alloc(size): 
traverse linked list, 
find block of size size in one of segments
remove it from the list and 
give it to the client

if segment.size >= size + 2 (2 for overhead), the segment is possible
2 search algorithms
- firstFit algo finds first possible segment 
(even if size 2, carves segment of size 4 from found of size 20)
- bestFit algo finds smallest possible segment 
(not wasting available space)

If no segment is found, return failure (or attempt deFrag)

carve block of size size+2 from found segment:
update free list segment with size = previous size - (size of carved block)

Update segment part to account for allocation
next points to null (0), size=size requested
data block of size size starts with base address that will be returned

return base address of block's data part to caller


de-alloc(object): append the object block to the end of free list
next of last current segment points to block disposed 
(points to next of free space which is at base address of obj - 2)

deFrag algo (optional) merges contiguous free spaces into 
larger available segments for alloc

freeList, alloc, dealloc, deFrag: use operations on heap array
next = heap[addr-2]
size = heap[addr-1]

drawLine(x1, y1, x2, y2):
let:
    x = x1;
    y = y1;
    dx = x2-x1;
    dy = y2-y1;
// use counter variables to count how many pixels 
// I went to the right (a) and how many up (b)
a=0, b=0;
Simplication assumption: x and y increase (dx, dy both positive)
while (a <= dx and b <= dy) //there is more work to do
    drawPixel(x+a, y+b)
    // decide to go right or up
    if going right, {a = a+1;}
    else            {b = b+1}
decide to go up/right based on desired angle dy/dx that we need to approch
with b/a (what we ended up doing so far)
if b/a > dy/dx b is too big for a -> make correction to the right and increase a
else go up
Division is expensive operation so
b/a > dy/dx equiv a * dy < b * dx 
let diff = a * dy - b * dx so condition (b/a > dy/dx) <-> (diff<0)
diff initially is 0 (a,b=0)
when a++, diff goes up by dy since diff from a*dy-b*dx becomes
(a+1)*dy-b*dx = a*dy-b*dx + dy
when b++, diff goes down by dx since diff from a*dy-b*dx becomes
a*dy-(b+1)*dx = a*dy-b*dx - dx

// decide to go right or up
if (diff<0) {a = a+1;diff = diff + dy}
else        {b = b+1; diff = diff - dx}

drawChar (index i, row i, column j):
    counter = 0
    while counter < 11:
        let address = 11 * i + j / 2;
        // we retrieve value to manipulate
        let value = Memory.peek[16384 + address];
        // Math.mod(j, 2) = 0
        if char is left part of word:
            // to remove 1st half and keep second & 0000 0000 1111 1111
            value = value & -256; since -256 = 1111 1111 0000 0000
            // to replace 1st half we shift to left charMap (x 2^8)
            // and | it to value 
            value = value | charMap[i] 
        else char is right part of word:
            // to remove 2nd half and keep 1st & 1111 1111 0000 0000
            value = value & 255 ;
            // to replace 2nd half  0000 0000 charMap | value 
            value = value | (charMap[i] * 256)

        do Memory.poke(address, value);
        counter++

// returns String representation of non-negative int
// starts from right to left, retrieving and chopping last digit
int2String(val) -> str:
    lastDigit = val % 10
    c = char representing lastDigit
    if (val < 10)
        return c (as a string)
    else 
        // chop off last digit through integer division -> shorten value
        // recursive call
        return int2String(val / 10).append(c) (as a string)

// returns int value of a string of digit chars
// assuming that str[0] represents most significant digit
// starts from left to right
string2Int():
    val = 0;
    for (i = 0 ... str.length) do:
        d = integer value of str[i]
        val = val * 10 + d;
    return val

Sys

Hardware contract: when computer is reset, program counter is set to 0,
so execution starts with instruction in ROM[0]
-> done by CPU and Program Counter hardware implementation

VM contract: the following bootstrap code should be placed 
at the top of the ROM, beginning in ROM[0] (in binary instructions):
stack pointer = 256
call Sys.init
-> done by VMTranslator

Jack contract: program execution starts with the function Main.main()
so there must be a class Main with a function main inside
-> done by every high-level Jack program

OS contract: Sys.init should initialize the OS, then call Main.main()
-> done by Sys.jack

halt: 
creates illusion that program is stopped, 
can be implemented using infinite loop

wait (miliseconds):
can be implemented using a loop, machine specific
with a delay factor as a constant
play with the value to get expected result: 
if computer is fast, value must be higher to slow it down
if computer is slow, value can be lower to speed it up
e.g. try to make it run for 5000 ms = 5s and compare with actual time
